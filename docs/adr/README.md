# Decision records

One file per decision, oldest first. A record says what was decided, what it cost and what was rejected, because the reasoning is the part that does not survive a rewrite of the code. A superseded record stays in place: the history of a decision is part of it.

- `0002-canonical-geometry.md` — Canonical tmux geometry; clients never resize the pane. **Superseded.**
- `0003-session-lifecycle.md` — pi extension session lifecycle is reason-branched. **Superseded.**
- `0004-scroll-anchor.md` — The scroll anchor is client-owned.
- `0005-remote-tls.md` — Remote access via loopback bind + `tailscale serve`, token + QR pairing. **Superseded.**

- `0010-exclusive-session-ownership.md` — Exclusive session ownership, with consented handoff.

- `0029-the-session-rides-raw-custom.md` — Our session layer rides MeshCore's `RAW_CUSTOM` payload.
- `0031-a-keeper-restart-can-keep-the-shells.md` — A keeper restart can keep the shells: fd custody and a terminal snapshot. **Proposed.**
- `0032-a-route-is-asked-for-not-waited-for.md` — A route is asked for, not waited for: a flooded `REQ` and a direct reply, because a repeater drops an advert after eight hops.
- `0033-a-flood-scope-is-followed-never-invented.md` — A flood scope is followed, never invented: the radio's own region, else one proven by an overheard scoped flood, else unscoped.
- `0034-the-view-is-made-valid-while-frozen.md` — A hold bounds output, not validity: the attach states the grid, and a resize or a `show` owes exactly one frame.
- `0035-a-request-is-answered-by-a-flood.md` — A route request is answered by a **flood**: an advert dies at eight hops, a `REQ` travels sixty-four, and without a path the phone cannot send a single record.
- `0036-one-radio-one-app.md` — One radio, one app: the lease, because Android will not arbitrate, and a second BLE central is accepted then dropped rather than refused.
- `0037-two-carriers-direct-by-default-flood-when-there-is-no-route.md` — A record rides a direct packet when a route is known and a `REQ` flood when none is, because `RAW_CUSTOM` cannot be flood-routed and the edge of coverage has no route to find.
- `0038-carrier-selection-escalate-on-silence.md` — How the carrier is chosen per send: direct by default, flood only after a direct attempt produced nothing, decayed by any arrival, with a flood always allowed to replace a dead path (mirroring the carrier is a feedback loop).
